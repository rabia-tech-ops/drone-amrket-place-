📌 Project Overview

Drone Marketplace Management System is a professional console-based C++ application developed using Object-Oriented Programming concepts.

The system simulates a real-world drone marketplace where customers, administrators, and operators can manage drone-related activities including buying, renting, monitoring, AI navigation, delivery tracking, and marketplace management.

This project was built as a beginner-to-intermediate level OOP project with a modern console UI, animations, authentication system, and multiple management panels.
